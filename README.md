WDcVHPPI
English

WDcVHPPI is a computational framework for predicting human–virus protein–protein interactions (PPIs).

The framework integrates protein features, human PPI network information, and viral taxonomic information within a Wide & Deep architecture to model complex virus–host interaction patterns.

Results

WDcVHPPI was evaluated across multiple viral groups, including SARS-CoV, Influenza, HIV, Papilloma, and Herpes.

The results demonstrate competitive and consistent predictive performance across diverse viral groups.
